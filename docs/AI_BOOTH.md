# AI бүүт — суулгах заавар

Арга хэмжээний цомог (фолдер) дээр AI зургийн бүүт нэмнэ. Зочин бүүтийн QR уншуулна → темплет сонгоно → QPay-ээр 5,000₮ төлнө → 1–4 хүн зогсоод зураг дарна → Google Nano Banana 2 зураг үүсгэнэ → лого, арга хэмжээний нэрийг код давхарлана → зочин утсандаа хадгална. Зочин зөвшөөрвөл зураг цомогт нэмэгдэх бөгөөд хаалттай линкээр бусад зурагтай хамт харагдана.

## 1. Google Gemini API түлхүүр авах

1. https://aistudio.google.com/apikey руу ороод **Create API key** дарна.
2. Google Cloud дээр billing (төлбөрийн карт) холбоно. Үнэгүй түвшинд зураг үүсгэх загвар ажиллахгүй бөгөөд оруулсан өгөгдөл сургалтад ашиглагдаж болзошгүй.
3. Google Cloud → Billing → **Budgets & alerts** хэсэгт сарын төсвийн хязгаар тавина. Жишээ нь $50 бол 80% хүрэхэд анхааруулга ирнэ.

## 2. Өгөгдлийн сан (migration)

Supabase Dashboard → **SQL Editor** руу ороод `supabase/migrations/20261006120000_ai_booth.sql` файлын агуулгыг бүтнээр нь хуулж **Run** дарна. CLI ашигладаг бол `supabase db push` гэж ажиллуулна.

Энэ migration дараах зүйлсийг хийнэ:

- `ai_templates`, `album_ai_booths`, `ai_jobs` хүснэгтүүдийг үүсгэнэ.
- `ai-booth` (хувийн) болон `ai-booth-assets` (нийтийн) storage bucket-уудыг үүсгэнэ.
- Шинэ жилийн **20 темплет** бэлэн оруулна.
- `photo_uploads` хүснэгтэд `source` багана нэмнэ (`upload` эсвэл `ai_booth`).

Migration-ийг дахин ажиллуулахад ямар нэг зүйл эвдрэхгүй.

## 3. Edge Function байршуулах

```bash
supabase secrets set GEMINI_API_KEY=AIza...
# (заавал биш) өөр загвар туршихад:
# supabase secrets set GEMINI_IMAGE_MODEL=gemini-3.1-flash-image

supabase functions deploy ai-booth --no-verify-jwt
```

- `QPAY_USERNAME`, `QPAY_PASSWORD`, `QPAY_INVOICE_CODE` нь одоо байгаа `qpay` функцтэй ижил secret тул дахин тохируулах шаардлагагүй.
- `--no-verify-jwt` заавал хэрэгтэй. QPay-ийн callback болон нэвтрээгүй зочид дуудах ёстой. Аюулгүй байдлыг функц өөрөө токеноор шалгадаг.

## 5. Ашиглах

**Зохион байгуулагч:**

1. Dashboard дээр цомгийн карт дээрх ✨ товчийг дарна.
2. Лого оруулж, байрлалыг сонгоно.
3. Арга хэмжээний нэрийг бичнэ.
4. Темплетүүдээ сонгоно.
5. **Хадгалах** дарна.
6. **Постер хэвлэх** дарж QR-тай A4 постер хэвлэнэ.
   - Утасны линк: `zuragchin.mn/booth/<token>`
   - Kiosk дэлгэцийн линк: `zuragchin.mn/booth/<token>?kiosk=1`. Үүнийг Chrome-ийн бүтэн дэлгэцийн горимоор ажиллуулна.

**Админ:**

- `/admin` → **AI темплет** табаас темплет засна. Жишээ зураг болон орчны лавлах зураг оруулах, идэвхжүүлэх, шинэ темплет нэмэх боломжтой.
- Үнэ (`price_mnt`) болон зохион байгуулагчийн хувийг (`owner_share`) зөвхөн админ өөрчилнө. Одоогоор SQL-ээр өөрчилнө:

```sql
update album_ai_booths set price_mnt = 5000, owner_share = 0.10 where album_id = '...';
```

## 6. Аюулгүй байдал ба нууцлал

| Линк | Хэнд | Юу хийх эрхтэй |
|---|---|---|
| Бүүтийн QR `/booth/<token>` | Дэгцэн дээр | Зөвхөн шинэ зураг **үүсгэнэ**, бусдын зургийг харахгүй |
| Үр дүнгийн линк `/booth/r/<token>` | Зураг авахуулсан хүн | Зөвхөн **өөрийн** нэг зургийг харна |
| Цомгийн хаалттай линк (одоо байгаа) | Группт илгээсэн хүмүүс | Цомгийн бүх зургийг (усан тэмдэгтэй) харна |

- **Төлбөр:** 1 төлбөр = 1 зураг. AI алдаа гарвал зочин нэмэлт төлбөргүйгээр дахин оролдоно. Нэг төлбөрт AI-г дээд тал нь 4 удаа дуудна.
- **Устгалт:** Зочны эх селфи болон үр дүн **30 хоногийн** дараа автоматаар устгагдана. Цомогт нэмэгдсэн хуулбар цомгийн хугацаагаар хадгалагдана.
- **QR солих:** Хэрэв QR алдагдвал тохиргооны хуудсанд ↻ товч дарж шинэ QR үүсгэнэ. Хуучин QR тэр даруй ажиллахаа болино.

## 7. Шинэ жилээс өмнө заавал турших

1. Туршилтын цомог үүсгээд AI бүүтийг асаана.
2. Түр хугацаанд үнийг 0 болгоно. Үнэ 0 үед QPay алгасагддаг.

   ```sql
   update album_ai_booths set price_mnt = 0 where album_id = '...';
   ```

3. 1, 2, 3, 4 хүнтэй, темплет бүрээр туршина. Нүүр зөв хадгалагдаж байгаа эсэх, лого болон бичиг AI-ийн дүрстэй давхцаж байгаа эсэхийг шалгана.
4. Үр дүн муу гарсан темплетийн prompt-ыг админ табаас засна. Хүнгүй "орчны лавлах зураг" оруулбал үр дүн илүү тогтвортой болно.
5. Туршилт дууссаны дараа үнийг 5000 болгож буцаана. Нэг удаа жинхэнэ QPay төлбөрөөр туршина.

## 8. Дараагийн шатанд хийх боломжтой

- Нүүрний ижил төстэй байдлыг автоматаар шалгах (face embedding). Одоогоор prompt-ын хатуу дүрэм болон "дахин оролдох" товч л байгаа.
- Үнэ, зохион байгуулагчийн хувийг админ UI-аас өөрчлөх.
- Багц үнэ (жишээ нь 3 зураг 12,000₮).
