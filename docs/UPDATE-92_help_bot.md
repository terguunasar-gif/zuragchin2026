# update-92 — Ухаалаг туслах чатбот («Туслах»)

Сайтын бүх хуудасны баруун доод буланд **«Туслах»** товч гарна (цомгийн хуудсанд зүүн доод буланд, дэлгэцийн слайдшоу болон AI бүүтийн хуудсанд гарахгүй).
Хэрэглэгч, зурагчин, зохион байгуулагч «яаж хийх вэ, хаана байна» гэж асуухад бот **хуудасны линк + товчны нэрээр алхам алхмаар** хариулна.

Жишээ: «Цомгоо нүүр хуудаснаас яаж нуух вэ?» → Самбар → Зохион байгуулагч таб → цомгийн карт дээрх ✏️ → «Төлөв»-ийг Ноорог болгох, эсвэл кодоор түгжих, эсвэл админд хандах.

## Хэрхэн ажилладаг вэ
- Хариултыг **Gemini** өгнө (одоо байгаа `GEMINI_API_KEY`-ийг ашиглана — шинэ бүртгэл хэрэггүй).
- Бот сайтын **гарын авлагаас** (`supabase/functions/help-bot/knowledge.md`) хариулна — кодноос цуглуулсан жинхэнэ зам, товчны нэрс.
- **Үнийг** Админ → Платформ тохиргооноос шууд уншина. Үнэ өөрчлөхөд бот автоматаар шинэ үнээр хариулна.
- Нэвтэрсэн хүний үүргийг (зурагчин/зохион байгуулагч/админ) мэдэж, түүнд тохирсон санал асуулт харуулна.
- Монгол, Англи, Орос, Хятад — сайтын сонгосон хэлээр хариулна.
- Мэдэхгүй зүйлийг зохиохгүй, «Холбоо барих» руу чиглүүлнэ. Хувийн захиалга, төлбөрийн мэдээлэл харахгүй.
- Хариулт бүрийн доор 👍 / 👎.

## Хамгаалалт ба зардал
- Нэг хүн (IP) цагт **30** асуулт, нийт өдөрт **3,000** асуулт (Админ → Чатбот табаас өөрчилнө). Админд хязгааргүй.
- Нэг асуулт ≈ 4,000–5,000 токен (гарын авлага орно). Gemini Flash-ийн үнээр нэг асуулт ойролцоогоор **$0.001–0.003** — өдөрт 300 асуулт ≈ сард $10–25. Google Cloud-ийн сарын төсвийн анхааруулга (AI бүүтэд тавьсан) үүнийг ч хамарна.
- IP-г хадгалахгүй, зөвхөн нэг талын хэш (hash) хадгална.

## Админ → «Чатбот» таб (шинэ)
- Асаах / унтраах, цагийн ба өдрийн хязгаар.
- **«Нэмэлт мэдлэг»** талбар — бот буруу хариулсан бол зөв хариултыг энд бичнэ. 5 минутын дотор ботод тусна, код өөрчлөх шаардлагагүй.
  (Нийтэд нээлттэй тохиргоонд хадгалагддаг тул нууц мэдээлэл бүү бич.)
- Хэрэглэгчдийн асуултууд: «Бүгд / 👎 Тус болоогүй / Алдаа» шүүлтүүр, 24 цаг ба 7 хоногийн тоо. 90 хоногоос хуучныг устгах товч.

## Суулгах

1. **SQL:** Supabase → SQL Editor → `supabase/migrations/20261119120000_help_bot.sql`-ийг бүтнээр нь хуулж **Run**. Дахин ажиллуулсан ч эвдрэхгүй.
2. **Edge Function** (нэг файл тул Dashboard эсвэл CLI аль алинаар болно):
   ```bash
   supabase functions deploy help-bot --no-verify-jwt
   ```
   Dashboard-аар: Edge Functions → **Deploy a new function** → нэр `help-bot` → `supabase/functions/help-bot/index.ts`-ийн агуулгыг бүтнээр нь хуулна → Deploy. Дараа нь функцийн тохиргоонд **Verify JWT** унтраалттай байх ёстой.
   - `GEMINI_API_KEY` secret аль хэдийн байгаа.
   - (заавал биш) `HELP_BOT_MODEL` — өөр Gemini загвар хэрэглэх бол. Анхдагч: `gemini-3.5-flash`; ажиллахгүй бол автоматаар `gemini-flash-latest` → `gemini-2.5-flash` руу шилжинэ.
3. **Frontend:** `src`, `scripts` хавтсуудыг repo-ийн **root**-д хуулна (`github/` хавтас дотор биш) → `git push` → Vercel автоматаар deploy.

## Турших
1. Нэвтрэлгүйгээр нүүр хуудсанд «Туслах» товч гарч байгааг шалгана. Санал болгосон асуулт дарахад хариулт ирнэ.
2. Зохион байгуулагч эрхээр: «Цомгоо нүүр хуудаснаас яаж нуух вэ?», «Цомгийн хугацааг яаж сунгах вэ?», «Нүүр хуудсанд нийтлэх үнэ хэд вэ?» — хариултын линк дарахад зөв хуудас нээгдэнэ үү.
3. Зурагчин эрхээр: «Зураг бүрт үнэ яаж тавих вэ?», «Мөнгөө яаж татах вэ?».
4. Хэлийг English болгоод асуухад англиар хариулна.
5. Админ → Чатбот табад асуултууд харагдаж байгааг, 👎 дарсан нь «Тус болоогүй» шүүлтүүрт орж байгааг шалгана.
6. Алдаа гарвал Supabase → Edge Functions → help-bot → Logs (`help-bot gemini:` мөр) болон Админ → Чатбот → «Алдаа» шүүлтүүр.

## Гарын авлагыг шинэчлэх (шинэ функц нэмэхэд)
1. `supabase/functions/help-bot/knowledge.md`-д тухайн хэсгийг нэмж засна.
2. `node scripts/build-help-bot.mjs` — мэдлэгийг `index.ts` руу суулгана.
3. `help-bot` функцийг дахин deploy хийнэ.
Жижиг засвар бол Админ → Чатбот → «Нэмэлт мэдлэг»-т бичихэд хангалттай.
