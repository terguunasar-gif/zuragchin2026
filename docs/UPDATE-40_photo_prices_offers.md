# update-40 — Зураг бүрийн үнэ, үнийн санал, 14 хоногийн татах хугацаа

## Юу өөрчлөгдсөн бэ

**Зурагчин**
- Цомгийн «Зураг удирдлага» хуудсанд зураг бүр дээр **татах үнэ** тавина (₮ дээр дарж засна, ↺ = цомгийн үнэ рүү буцаах).
- Олон зургийг ☐-ээр сонгоод **«Үнэ тавих»** товчоор нэг дор үнэ өгнө.
- Үнийн доод хэмжээ: 1,000₮ (`platform_settings.min_photo_price`).
- «Үнэ ба үнийн санал» хэсэгт цомгийн эзэн **санал хүлээн авах эсэх**, мөн **«X%-иас дээш саналыг автоматаар зөвшөөрөх»** тохиргоог хийнэ.
- Самбар → **«Үнийн санал (хариулаагүй)»** карт → `/dashboard/offers`: Зөвшөөрөх / Татгалзах / Эсрэг үнэ санал болгох.
- Мөн тэр хуудсанд **«Зураг шалгах»** хэрэгсэл байна. Олсон файлаа оруулахад захиалгын дугаар (ZM-…), огноо, худалдан авагчийн нэр, далдалсан утас харагдана. Бүтэн утсыг зөвхөн админ харна.

**Зочин**
- Зураг бүрийн доор **«Үнийн санал илгээх»** товч гарна. Санал нь үнийн хамгийн багадаа 50% байна. Нэг утаснаас нэг зурагт 24 цагт 1 санал, өдөрт нийт 10 санал илгээх боломжтой.
- Санал илгээсний дараа `/offer/<token>` хуудас нээгдэнэ. Зурагчин 48 цагийн дотор хариулна. Зөвшөөрвөл зочин 24 цагийн дотор QPay-ээр төлнө.
- Төлөхөөс өмнө **«Хувийн хэрэглээний лиценз»**-ийг заавал тэмдэглэнэ. Энэ нь сагс болон саналын аль алинд хамаарна. Мөн «14 хоногийн дотор татаж авна» анхааруулга гарна.
- Баримт хуудсанд **улаан тоолуур** гарна: «N хоног M цагийн дараа зураг устгагдана».

**Хамгаалалт**
- Худалдсан файл бүрт XMP + JPEG тайлбар хэлбэрээр зохиогч, «Personal use only», **захиалгын дугаар** суулгагдана. Пикселд хүрэхгүй тул чанар өөрчлөгдөхгүй.
- Захиалгын ID суулгасан хуулбар нь хувийн `purchases` bucket-д хадгалагдана. 14 хоногийн дараа татах линк ажиллахаа болино.
- Админ → Платформ → «Цэвэрлэх» товч нь хугацаа дууссан хуулбаруудыг давхар устгана.
- **Анхаар:** мета өгөгдлийг Facebook зэрэг сайтууд устгадаг, мөн screenshot-д үлдэхгүй. Үл үзэгдэх (пикселийн) усан тэмдэг нь 2-р шатны ажил.

## Суулгах дараалал

1. **SQL:** Supabase → SQL Editor дээр `supabase/migrations/20261028120000_photo_prices_offers.sql` файлыг бүтнээр нь хуулж **Run** дарна. Дахин ажиллуулсан ч эвдрэхгүй.
   - Өмнө төлөгдсөн бүх татах захиалгад «одооноос 14 хоног» хугацаа автоматаар тавигдана.
2. **Edge function:** Supabase → Edge Functions → `qpay` → кодыг `supabase/functions/qpay/index.ts`-ээр солиод **Deploy** хийнэ. `--no-verify-jwt` хэвээр байх ёстой.
   - (заавал биш) `SITE_URL` secret. Анхдагч утга нь `https://zuragchin.mn` бөгөөд SMS доторх линкэд ашиглагдана.
   - SMS ажиллуулах бол `SMS_API_URL`, `SMS_API_KEY`, `SMS_FROM` secret-үүдийг оруулна. Оруулаагүй бол зурагчин зочин руу утсаар холбогдох линкийг самбараас хуулж өгнө.
3. **Frontend:** `src` хавтсыг repo-ийн root-д хуулна (`github/` хавтас дотор биш). Дараа нь `git push` хийхэд Vercel автоматаар deploy хийнэ.

## Турших

1. Худалдах цомогт нэг зурагт тусгай үнэ (жишээ нь 8,000₮) тавина. Цомгийн хуудсанд тэр үнэ харагдаж байгааг шалгана.
2. Өөр утаснаас 5,000₮ санал илгээнэ. Самбарт санал гарч ирснийг шалгаад «Зөвшөөрөх» дарна.
3. `/offer/<token>` хуудсанд лицензийг тэмдэглээд жинхэнэ QPay-ээр төлнө. Баримт хуудсанд тоолуур гарч, «Татах» ажиллаж байгааг шалгана.
4. Татсан файлаа «Зураг шалгах» хэсэгт оруулахад ZM-… код гарч ирэх ёстой.

## Тохиргоо (platform_settings)

| key | анхдагч | утга |
|---|---|---|
| purchase_download_days | 14 | Төлсний дараа татах хугацаа (хоног) |
| offer_min_ratio | 0.5 | Саналын доод хувь |
| offer_response_hours | 48 | Зурагчин хариулах хугацаа |
| offer_pay_hours | 24 | Зөвшөөрсний дараа төлөх хугацаа |
| min_photo_price | 1000 | Зураг тус бүрийн үнийн доод хэмжээ |
