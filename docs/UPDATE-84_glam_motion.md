## Юу хийсэн бэ

**1. Видео үүсгэгч fal.ai руу шилжсэн** (`supabase/functions/ai-booth/veo.ts`)
- `FAL_KEY` secret байвал fal.ai-ын queue API-аар видео үүсгэнэ. Байхгүй бол хуучин Gemini/Veo замаар.
- Анхдагч загвар: **Gemini Omni Flash 1.2** (Google-ийн Veo-г орлосон шинэ загвар, fal.ai дээр) — 720p, дуутай, 9:16 / 16:9.
- `FAL_VIDEO_MODEL` secret-ээр загвараа солино (жишээ нь Kling 2.5 Turbo Pro). Код өөрчлөх шаардлагагүй.
- AI бүүт болон цомгийн видео хоёулаа нэг файлыг ашигладаг тул хоёулаа засагдана.

**2. Glam Motion загварын төрөл** (`album-video`)
- `ai_video_templates.style`: `action` (хуучин — эхний 2 сек царцаана, дараа нь үйлдэл) эсвэл `glam` (шинэ).
- `glam`: бүхэлдээ удаашруулсан (slow-motion) кино камер, 6 сек, үс/даавуу намирна, урд-арын parallax, хүмүүс байрлалаа хадгална.
- 8 бэлэн Glam темплет: Glam ойртолт, Гүн parallax, Алтан конфетти, Улаан хивс, Шампан тост, Даашинзны эргэлт, Өвлийн гялбаа, Салхин үс.
- Үнэ, орлогын хуваарилалт (90/10), QPay, «🎬 AI видео» хавтас, дэлгэцийн горим — **хуучнаараа**.

**3. Webhook** — fal.ai видео дуусмагц `/album-video/fal-webhook` дуудна → видео шууд Storage-д хадгалагдана.
Эзэн хуудсаа хаасан ч хүлээхгүй. Webhook-ийн агуулгад итгэхгүй — fal.ai-аас өөрсдийн түлхүүрээр дахин шалгадаг тул аюулгүй.

**4. Фронтенд**
- Видео үүсгэгч цонхонд «✨ Glam Motion» ба «🎬 Хөгжилтэй үйлдэл» гэж хоёр хэсэгт хуваагдана. Секунд нь сонгосон төрлөөр харагдана.
- Админ → AI видео загвар: «Төрөл» сонголт, Glam загварт GLAM тэмдэг.

## Суулгах

1. **fal.ai түлхүүр:** https://fal.ai → бүртгүүлэх → Billing-д карт холбох / кредит авах → **Dashboard → API Keys → Create key**. Сарын хязгаар (spending limit) тавина.
2. **SQL:** Supabase → SQL Editor → `supabase/migrations/20261116120000_glam_motion_video.sql`-ийг бүтнээр нь хуулж **Run**. Дахин ажиллуулсан ч эвдрэхгүй.
3. **Secrets** (Supabase → Edge Functions → Secrets):
   - `FAL_KEY` = fal.ai түлхүүр (**заавал**)
   - `FAL_VIDEO_MODEL` (заавал биш) = `google/gemini-omni-flash/v1.2/image-to-video` анхдагч. Kling ашиглах бол `fal-ai/kling-video/v2.5-turbo/pro/image-to-video`
   - `GLAM_VIDEO_SECONDS` (заавал биш) = 6
4. **Edge Functions — CLI-аар deploy хийнэ** (`album-video` нь `../ai-booth/veo.ts`-ийг импортолдог тул Dashboard-ийн нэг файлтай засварлагч ажиллахгүй):
   ```bash
   supabase functions deploy album-video --no-verify-jwt
   supabase functions deploy ai-booth --no-verify-jwt
   ```
5. **Frontend:** `src` хавтсыг repo-ийн root-д хуулна (`github/` дотор биш) → `git push` → Vercel автоматаар deploy.

## Турших

1. Админ эрхээр цомог нээж зураг дээр «AI видео» → **✨ Glam Ойртолт** → «Админ: төлбөргүй» тэмдэглээд үүсгэнэ.
2. 40–70 сек хүлээнэ. Видео «🎬 AI видео» хавтсанд гарч, тоглуулагдаж, татагдаж байгааг шалгана.
3. Supabase Logs-д `fal webhook` эсвэл алдаа байгаа эсэхийг харна. fal.ai Dashboard → Requests-д хүсэлт харагдана.
4. AI бүүтийн видеог нэг удаа туршина (0 үнэтэй туршилтын цомгоор).
5. 1, 2, 4 хүнтэй, босоо/хэвтээ зургаар туршиж, царай өөрчлөгдөж байгаа темплетийн prompt-ыг админ табаас засна.

## Шахалт (compression)

fal.ai-ын 720p MP4 нь 6–8 сек-д ≈ 3–6 MB (H.264), утсанд шууд тоглогдоно. Edge Function дээр FFmpeg байхгүй тул дахин шахахгүй.
Хэрэв Storage их зарцуулбал дараагийн шатанд видеог 30 хоногийн дараа цомгийн хугацаатай хамт устгах эсвэл 540p-д буулгах боломжтой.
